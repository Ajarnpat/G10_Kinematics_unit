This worksheet uses interval-average velocity at each midpoint time. It is an estimate of instantaneous velocity near that time for smoothly changing motion.
Show how minimum and maximum velocity are determined

For each 0.05 m interval, use the earliest and latest raw arrival times at its beginning and end. Since each position was measured in independent runs, this creates a conservative range rather than a statistical confidence interval.

Smallest possible interval time = earliest end arrival − latest start arrival → maximum velocity.
Largest possible interval time = latest end arrival − earliest start arrival → minimum velocity.

vmax = 0.05 / Δtmin; vmin = 0.05 / Δtmax. If Δtmin ≤ 0, no finite vmax can be inferred from these ranges.
